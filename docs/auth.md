Аутентификация реализована при помощи refresh и access токенов.

Для начала необходимо зарегистрироваться:
 - /auth/register - по логину и паролю (form-data "username", "password")
 - /auth/github - при помощи github аккаунта

 Если вы использовали гитхаб, то сразу получили пару токенов, если же нет, то надо отправить логин и пароль аналогично тому, как вы делали это при регистрации по пути /auth/login.

Далее для доступа к функционалу необходимо использовать access токен в качестве bearer token, пока он не истечет.

Для получения новой пары токенов отправьте свой refresh токен по пути /auth/refresh в формате json ("refresh_token":)

Также можно получить список активных сессий по пути /auth/sessions (нужен access token) и выйти из аккаунта /auth/logout (нужен refresh token)
