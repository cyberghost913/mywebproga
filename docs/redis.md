Кэш реализован при помощи Redis.

 - Кэш новостей - вся информация о новости, как и в БД, ttl = 5 min. 
 - Кэш пользователей - информация о ролях пользователя без чувствительных данных (id, username, is_active, is_admin, is_author), необходимая для предоставления доступа, ttl = 60 min

В обоих случаях выше сначала происходит обращение к кэшу, если там нет значения, то данные берутся из БД, потом кладутся в кэш, и в следующий раз берутся оттуда (если не истечет), если же данные есть в кэше, то запрос к БД не отправляется.

Информация о сессиях хранится только в кэше в том же виде, в котором она была в БД (), время жизни зависит от длительности refresh token'a.

Логирование реализовано при помощи подключаемого модуля logging. Логи сохраняются в файл "logs.log" в корне проекта и содержат информацию о том, какие данные мы получали, в какое время и были ли данные получены из кэша или выполнялся запрос к БД.
