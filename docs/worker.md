Для реализации фоновых задач были использованы **celery** и **redis rq**.

Всего есть две задачи:

    1. Уведомление о новой новости. Вызывается при создании новости, передается список email'ов.
    
    2. Еженедельный дайджест. Срабатывает автоматически каждое воскресенье в 22.00. Самостоятельно получает новости за предыдущую неделю и список электронных почт, для чего был создан синхронный движок базы данных postgresql.

Также для реализации идемпотентности при успешной отправке письма в базу данных вносится запись об этом, для чего был создан синхронный движок redis
