Для запуска необходимо клонировать этот репозиторий, запустить базу данных в контейнере, используя команду ```docker-compose up -d```, затем установить необходимые зависимости командой ```pip install -r requirements.txt```, далее, чтобы создать модели в базе данных и заполнить ее моковыми данными надо выполнить миграцию, для этого выполните команду ```alembic upgrade head``` (если не надо заполнять базу данных, а только лишь создать модели введите ```alembic upgrade 1```), после этого можно запускать сервис командой ```uvicorn app.main:app```. Желательно выполнять все вышеперечисленные действия в виртуальном окружении.
